# 中文决策记忆

只用这个结构保存需要跨会话复用的已确认产品决定。保持 `.super-pm/decisions.md` 简短、可读，不要把它写成对话记录。

```markdown
## <稳定决定 ID>：<决策问题>

- 状态：当前 | 已替代
- 日期：YYYY-MM-DD
- 决定：<已确认方向>
- 负向边界：<绝对不要；这次不做；硬约束；必须保护的品质>
- 证据：<支持当前决定的事实或实际结果>
- 待验证：<未解决的高影响假设>
- 下一步验证：<方法、样本、决策阈值和下一步动作>
- 重审触发：<重新打开决定的证据、日期、规模、成本或约束>
- 负责人：<已知负责人或待确认>
- 替代了：<决定 ID 或无>
- 被替代为：<决定 ID 或无>
- 变更原因：<替代旧决定时必填>
```

## 更新规则

1. 决定方向没有变化时保持 ID 稳定。
2. 决定本身没有变化时，原位更新证据、验证状态、负责人或重审触发。
3. 方向发生变化时，创建新 ID，把旧记录标为`已替代`，双向填写`替代了 / 被替代为`，并记录变更原因。
4. 文件记录与当前请求冲突时，先指出冲突，再决定采用哪个约束。
5. 保留已确认的历史；只有用户明确要求删除时才移除记录。
